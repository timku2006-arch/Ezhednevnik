# Ежедневник

Красивый личный ежедневник в браузере: задачи на день и цветные заметки.
Без бэкенда, регистрации и сборки. Данные хранятся в `localStorage` вашего браузера.

## Запуск

**Вариант 1.** Откройте файл `index.html` двойным кликом в любом современном браузере.

**Вариант 2** (локальный сервер одной командой, если удобнее):

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000.

> Шрифт Manrope подгружается из Google Fonts. Без интернета используется системный шрифт, а всё остальное работает как обычно.

## Возможности

**Задачи на день**
- добавить, отметить выполненной (с анимированной галочкой), отредактировать (кнопка ✎ или двойной клик), удалить с возможностью отменить;
- переключение дней: стрелки, чипы «Вчера / Сегодня / Завтра», календарь (точки отмечают дни с задачами, зелёные — дни, где всё выполнено), свайп по карточке дня на телефоне;
- прогресс дня: кольцо и полоса; когда выполнены все задачи, срабатывает конфетти.

**Заметки**
- заголовок и текст, 7 цветов карточек;
- закрепление важных: они переезжают наверх с плавной анимацией;
- поиск по заголовку и тексту с подсветкой совпадений;
- удаление с отменой.

**Интерфейс**
- светлая и тёмная тема (по умолчанию как в системе), переключение с круговым «раскрытием»;
- адаптивная вёрстка: на компьютере две колонки, на телефоне нижние вкладки;
- анимации длятся 180–400 мс; при включённой в системе настройке «уменьшить движение» (`prefers-reduced-motion`) анимации и конфетти отключаются.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `←` / `→` | предыдущий / следующий день |
| `T` | фокус в поле новой задачи |
| `N` | новая заметка |
| `/` | поиск по заметкам |
| `Ctrl/⌘ + Enter` | сохранить заметку в редакторе |
| `Esc` | закрыть календарь или редактор, отменить правку задачи |

## Структура

```
index.html          разметка и спрайт иконок
css/styles.css      темы (CSS-переменные), раскладка, анимации, адаптив
js/storage.js       чтение и запись состояния в localStorage
js/utils.js         даты, создание DOM-элементов, FLIP-анимация, тосты
js/theme.js         переключение светлой и тёмной темы
js/confetti.js      конфетти на canvas
js/calendar.js      всплывающий календарь
js/tasks.js         задачи, прогресс, навигация по дням
js/notes.js         заметки, поиск, редактор
js/app.js           точка входа: инициализация, вкладки, горячие клавиши
```

Скрипты подключаются обычными тегами `<script>` без ES-модулей, поэтому приложение работает и при открытии через `file://`.

Все данные лежат в ключе `ezhednevnik:v1` в `localStorage`. Чтобы начать с чистого листа, очистите данные сайта в браузере.
